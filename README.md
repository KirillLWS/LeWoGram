# LeWoGram

A simple private messenger for family and friends.
Self-hosted on Raspberry Pi.

## Stack
- Server: Python + FastAPI + SQLite
- Client: Flutter (Android)
- Auth: Invite-based, device fingerprint

## Features
- Text messages
- Photos, videos, files
- Voice messages, video circles
- Audio calls (WebRTC)
- Admin panel

## Self-hosted
Your data. Your server. Your rules.
